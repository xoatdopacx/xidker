---
name: Only original templates go on sale
description: What to do when the user asks to sell a copied website or copied prompts as a store template.
---

Templates sold on the store must be the user's own work or made from scratch here. Copies of other people's websites or prompts are not added, even when the user uploads them ready to go.
**Why:** buyers receive the full source to reuse and resell; a copied site carries someone else's design, code, text and brand.
**How to apply:** open any uploaded site before adding it. Look for a live domain, a copyright line, or a "made by" agency credit. If it is a copy, say so briefly in plain Vietnamese. Then offer an original template of the same kind, with an invented name, copy and pictures, like Rowan, Noa and Plinth.

Cases so far:
- 2026-10-23: motionsites.ai prompts (see motionsites-index.md). The user chose original templates instead.
- 2026-10-25: the user uploaded a downloaded copy of unitedcarriers.com and asked to add it. That is the Webflow site of United Carriers APAC Pty Ltd, built by the agency Bear Plus; its own local server script calls it a "clone". It was not added, and an original freight/logistics template was offered. The user turned that down and asked to "làm theo của file tôi gửi"; a close copy of that site was declined too, and nothing was built. The same day they re-sent the same site with only the name changed to "idk portfolio" (still Bear Plus credits, unitedcarriers.com Webflow ids, pictures loaded from that site's Webflow storage) and asked to add it to the Personal Source package; declined again. A name swap does not make a copied site original.
